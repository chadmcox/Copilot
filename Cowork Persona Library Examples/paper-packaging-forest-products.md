## Top 5 custom skills to build first

- **shift-handover-brief** (Supervisor; Machine Tender): Gather logs → flag issues → produce Word handover.
- **break-analysis** (Superintendent; Process Engineer): Gather break data → categorize → produce Excel analysis.
- **complaint-response** (Quality; Customer Service): Gather complaint and test data → analyze → draft email for approval.
- **fiber-cost-review** (Fiber Procurement; Finance): Pull costs → compare sources → produce Excel and deck.
- **ehs-daily-brief** (EHS Manager): Collect incidents → trend → produce Word brief.

## Top 5 connectors to demo

- **ERP (confirm)** (Finance; Supply Chain): Controller explains cost per ton quickly.
- **MES/QCS (confirm)** (Superintendent; Machine Tender): Superintendent reviews breaks before the morning meeting.
- **CMMS (confirm)** (Millwright): Mechanic gets prioritized work list.
- **EHS system (confirm)** (EHS Manager): EHS drafts daily brief in minutes.
- **Wood procurement (confirm)** (Fiber Procurement): Forester tracks deliveries and certification.
