## How to read this page

Each persona has three asks:

- **Quick win:** a small, everyday job that pays off right away.
- **Hand-off:** a multi-step job across several sources that would otherwise take an hour or more.
- **Recurring:** something scheduled or ongoing that keeps working without the person.

Every persona can use the standard Microsoft 365 sources (Outlook, Teams, meeting transcripts, SharePoint/OneDrive, calendar). **Systems** lists only the industry-specific systems that persona uses beyond those, marked *(confirm)* because they vary by company. Anything that sends, posts or schedules is a draft for the person's approval.

**Why the two industry personas:** Added Forester/Fiber Procurement Manager because wood fiber cost and sustainability certification drive margin, and Paper Machine Superintendent because machine efficiency is the core value driver.

## Personas and example asks

### 1. Finance

**Title:** Mill Controller  
**Duty:** Manage mill cost accounting, inventory, and capital reporting.  
**Systems:** Power BI, ERP (confirm; e.g., SAP S/4HANA), cost system (confirm)

- **Quick win:** "Which capex projects are over budget?" → Excel workbook
- **Hand-off:** "Analyze cost per ton by grade and energy and chemical costs vs. budget, and draft the monthly mill financial commentary" → Word doc
- **Recurring:** "Every morning, summarize yesterday's cost variances by mill area" → scheduled digest

### 2. HR

### 3. Frontline Worker

**Title:** Machine Tender / Back Tender  
**Duty:** Operate paper machine sections and monitor quality.  
**Systems:** QCS (confirm; e.g., ABB/Valmet), shift logbook (confirm)

- **Recurring:** "At the end of each shift, draft my handover with breaks, felt condition and near misses" → Word doc (one page)

## Top 5 custom skills to build first

- **shift-handover-brief** (Supervisor; Machine Tender): Gather logs → flag issues → produce Word handover. Start from [shift-handover-digest](../skills/shift-handover-digest.md).
- **break-analysis** (Superintendent; Process Engineer): Gather break data → categorize → produce Excel analysis.
- **complaint-response** (Quality; Customer Service): Gather complaint and test data → analyze → email draft. Start from [customer-escalation-pack](../skills/customer-escalation-pack.md).
- **fiber-cost-review** (Fiber Procurement; Finance): Pull costs → compare sources → produce Excel and deck.
- **ehs-daily-brief** (EHS Manager): Collect incidents → trend → produce Word brief. Start from [safety-incident-brief](../skills/safety-incident-brief.md).
## Top 5 connectors to demo

- **ERP (confirm)** (Finance; Supply Chain): Controller explains cost per ton quickly.
- **MES/QCS (confirm)** (Superintendent; Machine Tender): Superintendent reviews breaks before the morning meeting.
- **CMMS (confirm)** (Millwright): Mechanic gets prioritized work list.
- **EHS system (confirm)** (EHS Manager): EHS drafts daily brief in minutes.
- **Wood procurement (confirm)** (Fiber Procurement): Forester tracks deliveries and certification.
