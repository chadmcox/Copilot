## How to read this page

Each persona has three asks:

- **Quick win:** a small, everyday job that pays off right away.
- **Hand-off:** a multi-step job across several sources that would otherwise take an hour or more.
- **Recurring:** something scheduled or ongoing that keeps working without the person.

Every persona can use the standard Microsoft 365 sources (Outlook, Teams, meeting transcripts, SharePoint/OneDrive, calendar). **Systems** lists only the industry-specific systems that persona uses beyond those, marked *(confirm)* because they vary by company. Anything that sends, posts or schedules is a draft for the person's approval.

**Why the two industry personas:** Meetings & Events Planner covers group/MICE travel, a distinct revenue line with its own contracts; Travel Data & Savings Analyst owns the spend, savings, and emissions reporting that drives client renewals.

## Personas and example asks

### 1. Finance

**Title:** Travel Program Finance Manager  
**Duty:** Manage client billing, supplier rebates, and travel spend reconciliation.  
**Systems:** Power BI, Mid-office/back-office accounting (confirm), ERP (confirm)

- **Quick win:** "Which unbilled ticket and hotel transactions don't match client invoices?" → Excel workbook
- **Hand-off:** "Compare airline override and hotel commission receipts against targets by supplier, explain the gaps, and draft the rebate review for leadership" → Word doc
- **Recurring:** "Every morning, flag mismatches between yesterday's mid-office export and client invoices" → scheduled digest

### 2. HR

**Title:** Talent & Agent Workforce Partner  
**Duty:** Recruit, onboard, and retain travel counselors across contact centers.  
**Systems:** HRIS (confirm), workforce management (confirm)

- **Quick win:** "Which new-hire counselors haven't finished GDS certification?" → Excel workbook
- **Hand-off:** "Analyze counselor attrition by tenure and shift pattern over two quarters, find the drivers, and draft the retention update for leadership" → Word doc
- **Recurring:** "Every Friday, summarize certification status for the current new-hire class" → scheduled digest

### 3. Frontline Worker

**Title:** Travel Counselor / Reservations Agent  
**Duty:** Book, change, and ticket travel per client policy in GDS.  
**Systems:** GDS (confirm; e.g., Sabre, Amadeus), online booking tool (confirm)

- **Quick win:** "Which queued PNRs need reissue after schedule changes today?" → Excel workbook
- **Hand-off:** "Review my last month of exchanges, find the most common reasons for policy exceptions, and pull the matching client policy notes into one page" → Word doc (one page)
- **Recurring:** "At the start of each shift, list PNRs with ticketing deadlines today" → scheduled digest

### 4. Frontline Supervisor

## Top 5 custom skills to build first

- **disruption-traveler-roundup** (Safety/EHS; Operations/Facilities): Gather alerts and bookings → match affected travelers → produce contact list and client advisory draft. Start from [safety-incident-brief](../skills/safety-incident-brief.md).
- **client-qbr-builder** (Customer Service; Travel Data & Savings Analyst): Pull spend and service data → compute savings and compliance → build QBR deck. Start from [customer-escalation-pack](../skills/customer-escalation-pack.md).
- **adm-root-cause-log** (Quality; Finance): Collect debit memo emails → classify error and agent → update tracker with trends.
- **supplier-negotiation-pack** (Supply Chain/Procurement): Gather volume and contract terms → compare performance → produce negotiation deck.
- **rfp-response-kickoff** (Sales/Marketing): Read RFP → map questions to content library → assign owners in tracker and draft exec summary.

## Top 5 connectors to demo

- **GDS / booking data (confirm)** (Frontline Worker; Operations/Facilities): Agents ask for a reissue queue summary instead of scanning PNRs manually.
- **Mid-office / back-office accounting (confirm)** (Finance; Travel Data & Savings Analyst): Finance reconciles unbilled transactions with one ask each morning.
- **Traveler risk/tracking platform (confirm)** (Safety/EHS): Duty-of-care lead gets an affected-traveler list within minutes of an alert.
- **Expense system (confirm)** (Travel Data & Savings Analyst; Customer Service): Analysts spot hotel leakage by comparing booked vs. expensed nights.
- **Event registration platform (confirm)** (Meetings & Events Planner): Planners refresh rooming lists from registration changes automatically.
